Este repositorio ha sido creado con el único propósito de almacenar, organizar y respaldar las implementaciones de código, guías y ejercicios prácticos desarrollados durante las sesiones de la asignatura de **Estructuras de Datos y Algoritmos I (EDA-I)** en Java.

---

## 📁 Contenido del Repositorio

El proyecto contiene las carpetas con los Tipos de Datos Abstractos (TDAs), algoritmos de búsqueda y ejercicios de recursividad vistos directamente en clase. 

Cada directorio incluye por lo general:
* Interfaces que definen el comportamiento de las estructuras.
* Clases de lógica y manejo de nodos.
* Clases principales (`Main`) para probar los métodos en consola.

---

## ⚙️ Requisitos

* **Lenguaje:** Java SE 11 o superior.
* **IDE:** Desarrollado principalmente en Java, compatible con NetBeans, IntelliJ IDEA, Eclipse o VS Code.
